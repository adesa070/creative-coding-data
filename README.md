# Screen Time Garden

## Project Overview
Screen Time Garden is my Creative Coding and Dear Data 100 project. It explores my daily digital attention by tracking the amount of time I spend using five applications.

## Data Collection
I am collecting daily screen-time data for:
- TikTok
- Discord
- WhatsApp
- Safari
- TachiManga

Each observation records the date, application, minutes spent and category.

## Visualisation
The project uses Processing (Java) to represent each application as a plant. The height of each plant is based on the application's average daily screen time, calculated from the collected observations rather than individual daily readings.
